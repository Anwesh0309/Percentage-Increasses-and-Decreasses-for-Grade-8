# Percentage Increase and Decrease (Grade 8)

An interactive, gamified math learning module built with **React**, **Vite**, and **Tailwind CSS**, aligned with Grade 8 curriculum standards for **Percentage Increase & Decrease**.

## Features

- **Phase 1: Wonder & Curiosity** — Spark intuition with Leo's $80 jacket problem (+25% then −25%).
- **Phase 2: Story & Concept** — 8 visual narrative slides introducing multipliers, percentage changes, reverse percentages, and compound growth.
- **Phase 3: Interactive Simulation Stations** — Hands-on labs:
  - *Station 1: Percent Slider* (Grow & shrink visual bars with multipliers)
  - *Station 2: Price Tracker* (Compare before & after prices to calculate percentage change)
  - *Station 3: Change Chains* (Follow repeated, reverse, and compound changes)
- **Phase 4: Practice Game Worlds** — 10 themed worlds with 100 curated questions (10 questions per world) with diagrams, live hints, hearts/lives, streak counter, and star rewards:
  - World 1: Percent Port (Q1–10)
  - World 2: Multiplier Mall (Q11–20)
  - World 3: Increase Island (Q21–30)
  - World 4: Discount District (Q31–40)
  - World 5: Change Canyon (Q41–50)
  - World 6: Tax Town (Q51–60)
  - World 7: Reverse River (Q61–70)
  - World 8: Chain Cliffs (Q71–80)
  - World 9: Compound Cove (Q81–90)
  - World 10: Percent Champion (Q91–100)
- **Phase 5: Reflect & Scoreboard** — Interactive reflection question to consolidate learning, XP scoreboard, and celebration screen.
- **Full Voice Narration** — Complete audio voiceover for all phases, simulation guidance, and all 100 practice questions and hints.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```
